# Project OS

## Тестові дані для розробки

Окремі artisan-команди наповнюють dev-базу фейковими проєктами, задачами, коментарями й файлами. Кожну команду можна запускати окремо й скільки завгодно разів: дані щоразу додаються до наявних.

Задачі, коментарі й файли створюються лише в межах указаного проєкту:

- автор і виконавець задачі — власник або учасник цього проєкту;
- коментарі й файли потрапляють лише на задачі цього проєкту;
- автори коментарів — лише учасники цього проєкту.

Команди виконуються в контейнері `app`, тому dev-стек має бути запущений (`make local-up`).

### Швидкий старт

```bash
make seed-projects COUNT=1 MEMBERS=5    # виведе id: Created projects: #12
make seed-tasks PROJECT=12 COUNT=500
make seed-comments PROJECT=12 COUNT=2000
make seed-media PROJECT=12 COUNT=50
```

Коментарі й файли прикріплюються до задач, які вже є в проєкті, тому спершу запустіть `seed-tasks`.

### Команди

| Make | Параметри (за замовчуванням) | Що робить |
|---|---|---|
| `make seed-projects` | `COUNT=5`, `MEMBERS=3`, `OWNER=<user id>` | Створює проєкти. Власник — `OWNER` або випадковий наявний користувач. Учасники беруться з наявних користувачів з випадковою роллю; якщо їх бракує, створюються нові. |
| `make seed-tasks` | `PROJECT` (обов'язковий), `COUNT=50` | Створює задачі в проєкті `PROJECT`. |
| `make seed-comments` | `PROJECT` (обов'язковий), `COUNT=100`, `TASK=<id>` | Додає коментарі на випадкові задачі проєкту. З `TASK` — лише на цю задачу; вона має належати проєкту. |
| `make seed-media` | `PROJECT` (обов'язковий), `COUNT=20`, `TASK=<id>` | Прикріплює до задач проєкту файли (jpg, png, pdf); для зображень генеруються прев'ю. `TASK` працює так само, як у коментарях. |

Без make ті самі команди запускаються напряму:

```bash
docker compose exec app php artisan seed:tasks 12 --count=500
docker compose exec app php artisan seed:comments 12 --count=100 --task=7
```

Опис усіх опцій: `docker compose exec app php artisan help seed:media`.

В оточенні `production` команди не запускаються без `--force`.
